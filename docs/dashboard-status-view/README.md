# Status View Spec

This folder contains the finalized visual specification and implementation
plan for the `t69` dashboard status view.

## Files

- `status-view-spec.md`: FINAL mock-driven spec — layout (Option A),
  wordmark header, exact palette, row behavior, held-time tiers.
- `implementation-plan.md`: full tech plan — file layout, build phases,
  agent workflow (Haiku workers / Sonnet reviewers), complete testing plan
  (unit, regression, Textual pilot, human-simulation, manual human
  checklist), acceptance criteria, risks.
- `img*.png`: design-round reference images.
